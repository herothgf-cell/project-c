## 핵심 구분

- **사용자 목표:** 기억을 삭제해 대상의 행동을 바꾸는 퍼즐, 조작은 빠르게 익히되 해법은 깊게, 기획 → 작은 플레이 버전 → 테스트 → 확장.
- **이번 기획의 제안:** 사건 단위 기억 삭제·최신 근거 선택·턴 실행 분리·한 방 단위 퍼즐·스토리 선택의 후속 기록.
- **미확정:** 엔진(Godot 2D + GDScript 우선 검토), 출시 플랫폼, 가격, 본편 분량·일정, 스토리/규칙 최종 확정.
