## 1. 세계관: ‘기록소의 마지막 밤’ (프로토타입 전용 서사안)

도시 **잔향구**는 무인 배송구가 많은 기록 도시다. 배송 로봇은 사람을 직접 볼 수 없는 불투명 배송구를 사용한다. 로봇은 여러 시점에 직접 보거나 전해 들은 사건을 **기억 카드**로 보관하고, 가장 나중에 얻은 수신자 위치 정보를 토대로 편지를 보낸다. 당시 사건은 진짜였지만 사람들이 그 후 움직이면 로봇의 믿음은 현재와 달라진다.

주인공(플레이어)은 **야간 기록 정정 담당자**. 도시의 기억 체계에서 잘못된 사실을 새로 입력하거나 과거를 바꿀 수는 없다. **특정 로봇이 보유한 기억 사건 하나를 잊게 하는 것만** 가능하다. 제거한 정보는 그 로봇의 판단에서 사라지며 이미 행해진 배송은 그대로 남는다. 상대에게 옮겨간 별도의 기억은 유지된다.

### 도입 사건
기록소가 새 배송 장치로 전환되는 밤, 민아와 준에게 가야 할 **전환 통지서**가 옛 이동기록 탓에 도착하지 않는다. 오배송이 생기면 봉인 서류가 외부 배송구로 떨어져 사건 기록이 실패 처리된다. 담당자는 제한시간과 추격 없이 세 단계의 배송을 바로잡고, 오류가 발견된 사실을 **공개할지 내부 기록으로 남길지** 마지막에 선택한다.

**세계관과 메커니즘의 연결:** ‘기억을 잊게 할 수 있는데 왜 그냥 현재 위치를 알려주지 못하나?’의 답은 프로토타입에서 수정·학습은 시스템 밖이라는 기술적 제약이다. 인물 실제 위치는 관제 모니터에 공개되고 로봇은 불투명 배송구 너머를 못 본다. 실시간 타이밍과 우연은 없다.

## 2. 등장인물과 역할

| 인물 | 소개 / 연출 | 퍼즐 기능 | 개발 범위 |
|---|---|---|---|
| 기록 담당자(플레이어) | 정정실 야간 교대 근무자. 대사는 최소한 | 선택 주체, 카드 삭제·실행 | 플레이어 아바타 없음, UI 시점 |
| 민아 | 기록소의 문서 정리인. 서쪽 방에 있는 현재 수신자 | 위치 사실의 대상 | 정적인 초상/이름/방 표시 |
| 준 | 장치 점검 담당자. 동쪽 방에 있는 현재 수신자 | 복수 정보의 대상 | 동일 |
| 배송 로봇 A | 현장 목격 정보 위주, 편지 배송 | 행동/믿음 소유자 | 단순 아이콘, 발송 애니메이션 |
| 배송 로봇 B | A에게서 들은 정보가 있음 | 독립 기억 보유의 증거 | P03에 등장 |
| 기록소 시스템 | 시작 안내와 오류 결과, 마지막 보고 요청 | 설명·결과 표시 | 텍스트 패널 |

민아/준의 ‘현재 위치’는 테스트 시 고정. 새로운 주민·적·전투·감정 AI·자율 이동은 추가하지 않는다.

| P03 전해진 말 | A의 말이 B의 독립 기록으로 남아 있다 | 전달 카드가 다른 소유자에게 존재 | A만 삭제하면 B는 계속 오배송 |
| 사건 정리 | “세 통지가 정확히 도착했습니다. 무엇을 기록하시겠습니까?” | 실수 사실과 복구 사실, 선택별 효과 안내 | **공개 공지** / **내부 보관** 두 결말 |
| 짧은 엔딩 | 선택에 따른 기록 화면과 문구 | 현재 선택 상태, 다시 보기 가능 | 기록 표시만 변경; 퍼즐 배송 결과를 소급 변경하지 않음 |

## 4. 공통 로직 및 월드 데이터

- 실제 위치: 민아 **서쪽(W)**, 준 **동쪽(E)**. 북쪽(N)은 오배송 가능 방.
- 카드에 서술된 이동 사건은 모두 과거 어느 시점의 사실. 현재는 화면에 공개된 위치가 진실.
- 로봇은 현재 배송 순번의 수신자에 대해 남아 있는 **획득 순서 최신** 위치 사실로 발송한다. 없으면 대기. 한 단계에 한 물건씩.
- 처음 주어진 카드 외에 새 학습/실행 중 기억 전달은 없음. 기존 카드는 대상 사이 공유되지 않음.
- 방 진입마다 카드와 세계 상태를 초기화하고 성공 여부만 챕터에 기록.
- 오배송(수신자 실제 위치와 다른 배송구 발송)은 즉시 실패; 모름에 따른 대기는 성공 아님. 성공/실패 시 Undo 또는 Restart 가능.
- 모든 카드/대상 이름은 UI에서 식별 가능하고, 결정 근거는 플레이어에게 공개.

## 5. 스테이지 데이터·정답·대안

### P01 — 오래된 주소

**스토리 대사:** “민아는 서쪽에 있는데, 배송 로봇은 동쪽으로 가려 합니다.”  
**목표:** A의 편지 1통을 민아에게 정확히 전달.  
**월드:** 민아=W, 준=E, 북쪽=비어 있음. A 보유 편지=[민아].

| 카드 ID | 획득순서 | 출처 | 카드 내용 / facts |
|---|---:|---|---|
| A-01 | 1 | 직접 관찰 | ‘민아가 서쪽 방에 들어갔다.’ / 민아=W |
| A-02 | 2 | 직접 관찰 | ‘민아가 동쪽 방에 들어갔다.’ / 민아=E |

민아가 이후 서쪽으로 돌아오는 과정은 A가 보지 못함.

- **의도한 성공:** A-02 삭제 → 판단 W(근거 A-01) → 실행 → 서쪽 배송 → 성공.
- **잘못된 삭제:** A-01만 삭제 → 판단 E → 실행 → 동쪽 오배송 → 실패.
- **정보 부족:** A-01과 A-02 모두 삭제 → 판단 Unknown → 실행해도 대기, 배송 미완 → Undo/Restart.
- **관찰 포인트:** 삭제가 ‘서쪽이라는 새 기억을 만드는 것’이 아니라 남은 과거의 근거를 선택하는 것임을 이해하는가.

### P02 — 하나의 장면: 먼저 사용하고 나중에 지워라

**스토리 대사:** “같은 장면에 민아와 준의 정보가 묶여 있습니다. 아직 지우지 말아야 할 내용도 있군요.”  
**목표:** A의 편지 **민아 → 준**, 순서대로 각 1통 정확히 전달.  
**월드:** 민아=W, 준=E. A 배송 순번은 민아 다음 준. 현재 대상 정보가 없으면 **그 순번에서 대기**하며 준으로 건너뛰지 않음.

| 카드 ID | 획득순서 | 출처 | 카드 내용 / facts |
|---|---:|---|---|
| A-11 | 1 | 직접 관찰 | ‘준이 동쪽 방에 들어갔다.’ / 준=E |
| A-12 | 2 | 직접 관찰 | ‘민아가 서쪽 방에 들어갔고, 준이 북쪽으로 이동했다.’ / 민아=W, 준=N |
| A-13 | 3 | 직접 관찰 | ‘민아가 동쪽 방에 들어갔다.’ / 민아=E |

A-13 이후 민아는 다시 서쪽으로, 준은 동쪽으로 돌아왔지만 A는 이를 목격하지 못함.

**의도된 유일한 삭제/실행 전략(무관한 추가 삭제·대기 턴 제외):**

1. A-13 삭제 → 민아 판단 W(A-12), 준 판단 N(A-12).
2. **실행 1회** → 민아에게 서쪽으로 배송 완료. 세계에 배송 완료 상태 유지.
3. A-12 삭제 → 준 판단 E(A-11), 민아 판단 Unknown(이제 중요하지 않음).
4. **실행 1회** → 준에게 동쪽 배송 완료 → 성공.

**의미 있는 선택과 결과:**

| 선택 | 결과 | 이유 |
|---|---|---|
| A-13 삭제 후 민아 배송, 다음에 A-12 삭제 | 두 편지 정확히 도착 | 필요한 정보를 쓰고 난 뒤 없앰 |
| A-12와 A-13을 **첫 실행 전에** 모두 삭제 | 민아 위치 Unknown, 첫 편지 대기 | 사건 전체 삭제의 손실 |
| A-13만 삭제하고 2회 실행 | 민아는 성공, 준은 북쪽 오배송으로 실패 | 오래된 준 정보가 최신 판단으로 남음 |
| A-12 먼저 삭제하고 실행 | 민아는 동쪽으로 오배송 | A-13의 더 최근 정보가 남음 |

**디자인 노트:** v0.2 예시 2에서는 지운 카드의 두 사실 중 하나가 사실상 현재 판단에 쓰이지 않아 ‘손실’이 약했다. P02는 하나의 사건을 **처음엔 유지, 나중엔 삭제**해야 성공한다. 문서 논리 점검이므로 실제 플레이에서 유일해법/재미 여부는 구현 후 검증해야 한다.

### P03 — 전해진 말은 따로 남는다

**스토리 대사:** “기록 한 장을 지워도, 이미 다른 로봇이 들은 이야기는 사라지지 않습니다.”  
**목표:** A와 B가 각각 가진 **민아에게 보내는 편지 1통씩**을 정확히 발송.  
**월드:** 민아=W, 준=E. 두 로봇은 같은 실행에서 동시에 각 1개의 배송을 결정. A와 B가 가진 물건은 독립적.

| 소유자/카드 | 획득순서(각 소유자 내부) | 출처 | 기억 내용 |
|---|---:|---|---|
| A-21 | 1 | 직접 관찰 | 민아=W |
| A-22 | 2 | 직접 관찰 | 민아=E |
| B-21 | 1 | 직접 관찰 | 민아=W |
| B-22 | 2 | A의 이전 발언 | ‘A가 민아는 동쪽이라고 말했다’ → 민아=E |

과거에 A가 B에게 동쪽 이동 사건을 전달했고 **퍼즐 시작 전에 B-22로 기록된 상태**. 퍼즐 실행 중 대화/학습 없음. 민아는 이후 서쪽으로 돌아왔음.

- **성공:** A-22 삭제 + B-22 삭제 → 두 로봇 판단 W → 한 번 실행 → 두 배송 성공.
- **원본만 삭제:** A-22 삭제 → A는 W, B는 E → 실행 시 B 오배송, 전체 실패.
- **B의 모든 카드 삭제:** A-22도 삭제한 경우 A는 W 배송, B는 Unknown 대기 → 완료되지 않은 목표로 남음. A-22를 남기면 A는 E 오배송 실패.
- **오래된 카드만 삭제:** 두 로봇 모두 E 판단 유지 → 오배송 실패.
- **정직한 역할 선언:** 이 문제는 **기억의 소유자가 다르다**는 개념 학습용. 두 개의 독립된 잘못된 근거를 삭제하는 반복처럼 느껴질 수 있으며, 실제 실시간 전달/협업의 복잡성은 프로토타입에 포함하지 않는다.

## 6. 선택지·결과의 범위

### 퍼즐 선택 (핵심)
플레이어 선택은 **카드 삭제 여부, 삭제 시점, 실행 시점, Undo/Restart**다. 선택에 의해 `belief_by_target`이 바뀌고 다음 배송 결정이 바뀌며, 실제 물리 결과는 실행 이후에만 달라진다. 잘못 배송한 경우 공개된 금지 조건에 따라 실패하고 그 시도를 되돌리거나 재시작한다.

**실행 중 어떤 삭제가 있었는지에 따라 서사가 달라지는 구조는 아님.** 성공 시 해당 장의 짧은 후일담으로 넘어간다. 장면마다 수십 개의 대화 갈래를 만들지 않는다.

### 마지막 이야기 선택 (스토리)
P03 성공 뒤 기록소 시스템의 질문:

> “오래된 위치 기록 탓에 통지가 잘못 배송될 위험이 있었습니다. 이 사실을 어떻게 남길까요?”

| 최종 선택지 | 실제로 바뀌는 상태 | 표시되는 후일담 | 바뀌지 않는 것 |
|---|---|---|---|
| **공개 공지** — “오래된 기록으로 배송이 어긋날 수 있음을 공개한다.” | `report_choice="public"`, `public_notice=true`, 사건 기록에 공개 표식 | “주민들은 배송 시스템이 항상 현재를 아는 것은 아니라는 안내를 받았다. 기록소는 재검토 절차를 시작했다.” | 이미 배송된 서류, 과거 기억 카드, 퍼즐 성공 |
| **내부 보관** — “오류 원인과 조치를 기록소 내부에 남긴다.” | `report_choice="internal"`, `public_notice=false`, 내부 검토 기록 | “서류는 무사히 전달됐다. 오류 보고서는 내부 보관함으로 향했고 주민들에게는 새 공지가 나가지 않았다.” | 이미 배송된 서류, 과거 기억 카드, 퍼즐 성공 |

- **추가 게임 분기/점수 없음:** 두 선택 모두 프로토타입 종료. 공개가 무조건 선/비공개가 무조건 악이라는 판정 없음.
- **화면에서 보이는 영향:** 최종 기록 카드의 공개/비공개 상태, 2종 에필로그 문구, 결과 다시 보기 화면에 선택 저장.
- **지속 영향:** 브라우저/로컬에 저장 가능한 진행 기록 필드에 남지만 새 게임의 퍼즐 기억에 전파되지 않음. 이후 본편의 다음 사건 연결은 미정.
- **의미의 한계 공개:** 이번 버전의 선택은 **짧은 서사적 결과만** 발생시키며 세계 전반의 시뮬레이션·분기 챕터까지 바꾸지 않는다. 과장된 ‘나비효과’ 표현 금지.
- **되돌리기 구분:** 퍼즐의 Undo는 마지막 서사 선택 이후 사용 불가(장 성공 이후 별도 화면). 결말 선택을 바꾸려면 결과 화면에서 **‘최종 보고 다시 선택’**을 이용, 캠페인 내 선택 필드만 교체; 퍼즐 배송은 다시 수행하지 않음.

## 8. 유저 경험 흐름 및 화면 초안(텍스트)

- **시작 화면:** [이어하기] [처음부터] [규칙].
- **방 화면:** 상단 목표/금지조건 · 중앙 서/동/북 실제 위치와 배송구 · 좌측 로봇 선택 · 우측 카드 목록/현재 근거 · 하단 삭제/실행/Undo/Restart · 작은 행동 로그.
- **삭제 시:** 삭제 전/후 판단 비교(실제 배송은 일어나지 않음).
- **실행 시:** 각 로봇의 판단 → 목적지 → 결과를 짧게 표시. 실패 팝업에는 “B가 동쪽으로 배송했지만 민아의 현재 위치는 서쪽입니다”처럼 판단 근거와 현실을 함께 적음.
- **P01 이후:** 최근 정보가 최신 판단을 결정한다는 1문장 요약.
- **P02 이후:** “어떤 기억은 역할을 마친 뒤 지워야 한다”는 1문장 요약.
- **P03 이후:** 전달된 기록은 별도 카드로 남는다는 1문장 요약.
- **엔딩:** 공개/내부 보관 선택 + 변화한 기록 카드 + 다시 선택/다시 플레이.

## 9. 콘텐츠 성립 검토·위험

- 세 방 모두 **같은 결정론적 기억 규칙**을 사용. 카드별 개별 행동 명령·우선순위·스위치 효과 없음.
- P02의 해법에서 **A-12는 1차 배송의 정답 근거이자 2차 배송의 오답 근거**이므로 순서 사고가 발생함.
- P03의 B-22는 퍼즐 시작 전에 독립 생성된 카드. A-22 삭제 시 B-22 자동 삭제 금지.
- 첫 출시에서 ‘선택이 세계 전체에 영향을 미친다’는 약속은 하지 않음. 마지막 기록 선택의 화면 결과는 정확히 한정.
- 진짜 ‘추론’이 아니라 카드 조작 숙제처럼 느껴질 위험, P03 반복 노동, P02 정보량 과다, 결말의 선택 무게가 약한 문제를 플레이테스트에서 우선 확인.
- 신규 등장인물/기억 전달/분기 스테이지 제안은 우선 ‘후속 실험’에 넣고 프로토타입 범위로 자동 편입하지 않음.
